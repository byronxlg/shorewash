Accessibility

We want everyone to be able to use this site, whatever device or assistive technology they use.

What we have done

  • All content is plain HTML that works without JavaScript, including the quote form.
  • Every image has a text description. With JavaScript enabled, the before-and-after sliders work with arrow keys and screen readers. Without JavaScript, both photographs appear side by side.
  • Text and controls use contrasting colours, with visible keyboard focus and a skip link to the main content.
  • Text can be resized to 200% without loss of content, and the layout adapts to any screen width.
  • Animation is disabled when your system asks for reduced motion.

Tell us about a problem
